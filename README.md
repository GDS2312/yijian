# 弈见 · 象棋分析与打谱

用于个人象棋研究的浏览器工具。支持走谱、分支、局面笔记、导入导出、内置基础谱、浏览器 Fairy-Stockfish NNUE 分析及局势曲线。

网页棋谱保存在访问者自己的浏览器，请用完整棋谱 JSON 导出备份。GitHub Pages 静态版本未连接云库代理与本机 GPT 讲解。

首次启用引擎会自动刷新一次以准备浏览器环境；若浏览器不支持，可继续打谱。引擎和 NNUE 资源均从本站加载。

## 第三方许可

Fairy-Stockfish WASM 的 GPL 许可及对应源码在 `licenses/`；NNUE 来源与许可说明也在该目录。服务工作线程由本项目实现，不依赖外部 CDN。

本仓库仅保存静态发布文件，不含用户棋谱、账号凭证或本机 Codex 服务。
